# Changelog

All notable changes to the Budget Tracker Application will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Improved project structure with organized directories
- Comprehensive documentation including CONTRIBUTING.md, CODE_OF_CONDUCT.md, and LICENSE
- Enhanced README with better formatting and clarity
- Architecture documentation in docs/ARCHITECTURE.md
- Detailed setup instructions in docs/SETUP.md

### Changed
- Reorganized project files into src/, include/, resources/, and build/ directories
- Updated build configuration to reflect new folder structure
- Improved .gitignore to exclude build artifacts and database files

## [1.0.0] - Initial Release

### Added
- User authentication system with login and registration
- Income and expense transaction management
- Transaction categorization and subcategorization
- SQLite database integration for data persistence
- Visual data representation with Qt Charts
- Balance sheet view showing all transactions
- Category-specific transaction filtering
- Real-time balance calculation
- User-friendly Qt Widgets-based interface

### Features
- Secure user accounts with unique identifiers
- Add income with custom categories and amounts
- Add expenses with custom categories and amounts
- View all transactions in chronological order
- Filter transactions by category
- Interactive line charts showing financial trends
- Balance, income, and expense visualization over time
- Cross-platform desktop application
